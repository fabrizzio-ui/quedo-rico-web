# Proyecto Quedó Rico

- Web en español, para universitarios de Trujillo, pensada primero para celular.
- Colores: Verde Rescate #1F5C3F, Naranja Antojo #E07B1A, Crema Kraft #F6EEDF, Gris Carbón #2B2B2B.
- Tipografías: Poppins (títulos y precios) y Nunito (textos).
- Usar el logo de la carpeta logo/ sin modificarlo.
- Seguir brief.md (funcionamiento) y diseno.md (diseño). Las imágenes de referencias/ muestran el estilo buscado.
- Negocios y precios ficticios (ver brief.md).
- El pago con Yape/Plin es una simulación: no se cobra dinero real.
- El asistente "Rico" funciona con respuestas preparadas (opciones tocables), sin servicios de pago.
- Sitio sencillo que se pueda subir gratis a internet, sin servidores ni bases de datos.
